# 프로젝트 개요(Title & Description)
프로젝트 이름 : 게시판 만들기 

한 줄 소개 : 비회원 게시판

배경 및 목적 : 개발 연습


## 주요 기능
< 목록 페이지 >
- 게시글 목록 출력
- 등록 버튼 클릭 시 등록 페이지로 이동
- 제목 클릭 시 상세 페이지로 이동
- 한 페이지에 게시글 10개가 넘으면 다음 페이지 버튼 생성
필수 항목: 등록일시, 제목, 이름, 등록, 페이징

< 등록 페이지 >
- 게시글 등록
- 제목, 이름, 비밀번호, 내용을 입력한 후 등록 버튼 시 글 등록 가능 (하나라도 미입력 됐을 시에는 "모든 항목을 입력해 주세요."출력)
- 목록으로 돌아가기 버튼 생성
필수 항목: 제목, 이름, 비밀번호, 내용, 등록, 목록 

< 상세 페이지 >
- 게시글 상세 내용 출력
- 목록으로 돌아가기 버튼 생성
- 수정 및 삭제 버튼 생성
필수 항목: 등록일시, 이름, 제목, 내용, 수정 , 삭제, 목록

< 수정 페이지 >
- 이전에 등록된 내용 출력
- 수전 버튼 클릭 시 비밀번호 팝업 출력, 일치 시 수정 페이지로 이동 (비밀번호 불일치 시 "비밀번호가 일치하지 않습니다."출력)

< 삭제 페이지 >
- 삭제 버튼 클릭 시 비밀번호 확인 팝업 출력, 일치 시 "정말 삭제하시겠습니까?"라는 메시지에서 확인 버튼을 누르면 "삭제되었습니다."라는 메시지가 출력되면서 게시글 목록 페이지로 이동
  (비밀번호 불일치 시 "비밀번호가 일치하지 않습니다."출력)

## 기술 스택
< Frontend >
- JavaScript : 웹 페이지에 동적인 기능을 더해주는 프로그램이 언어
- CSS : HTML 문서의 시각적 디자인과 레이아웃을 꾸미는 스타일 시트
- Vanilla JavaScript : React, vue, jQuery같은 외부 라이브러리나 프레임워크를 사용하지 않고 오직 순수한 자바스크립트만 사용
- Thymeleaf : 서버 사이드 렌더링(SSR)을 지원하는 자바 템플릿 엔진

< Backend >
- Spring Boot : 자바(Java) 기반의 웹 애플리케이션을 쉽고 빠르게 만들 수 있도록 도와주는 스프링(Spring) 프레임워크의 확장 도구
- REST API : 웹 기반 통신에서 자원을 이름으로 구분하여 상태를 주고받는 REST 아키텍처 스타일의 인터페이스

< Database >
- H2 : 자바로 작성된 초경량 관계형 데이터베이스 관리 시스템(RDBMS)
